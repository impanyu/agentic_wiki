# Single root routing

Every wiki page and web app has a **profile**: what the page covers or what the app does, built from its title, summary, section headings (wiki) or app type and input fields (apps), and index meanings, and embedded (`page_profiles`, `app/routing/profiles.ts`). Profiles are refreshed when a page is created and whenever a saved change records a version; any page whose profile is missing or older than its last update is rebuilt before a search.

After the fast paths miss (an identical question already routed, or an explicit fork, which skips reuse), navigation creates one `root-routing` agent. The request is embedded — a typed question as written, a pasted URL by its fetched content (title and summary), never by its address — and compared with the profiles of every page the user may open (their own and public pages, same language). The nearest five profiles go to one judge that picks at most one candidate: **high** (same subject, same scope, right kind: tool requests need an app) reuses it; **uncertain** checks the page itself; **none** hands the request to the generator, which creates a new page. Rejection never searches further down the list.

A match opens a wiki page directly with the existing freshness checks; for an app, the same root extracts declared input parameters and runs it. Missing inputs are not invented. Storage-scope, ownership, aliases and per-user replacements still apply.

## Link context

Clicking linked text inside a page sends the visible text plus a `origin` (the page and the highlighted passage, index entry or chat passage) to `contextualLinkQuestion`. The routing model first decides whether the text is **standalone**: proper names (Pakistan, WHO), fixed terms and established concepts (photosynthesis, GDP), qualified phrases, URLs and explicit questions stay exactly as written, even when the passage relates them to the page subject. Only text that is not self-sufficient (a bare common noun such as *transmission*, an abbreviation, a back reference, or a name with several well-known meanings such as *Python*) receives the minimum nearby context. A rewrite must keep the clicked text as its subject; `Pakistan` on an India page never becomes `India-Pakistan border`, and the server drops any rewrite that does not contain the original text.
